## Overview

Yellow DirkShark empowers you to discover, create, and share LEGO projects using pieces from your existing collections. Browse thousands of user-generated designs, build custom models virtually, and access step-by-step instructions without buying new bricks. Unlock creativity with a vast library of MOCs (My Own Creations) and inventory tools that track your LEGO parts.

<Callout kind="info">
Yellow DirkShark connects your physical collection to digital designs, saving time and inspiring endless builds.
</Callout>

## Quick Start

Get building in under 5 minutes. Follow these steps to dive into your first project.

<Steps>
  <Step title="Sign Up" icon="user-plus">

## Integrate with Your Apps

Fetch projects programmatically to embed Yellow DirkShark in your tools.

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  const response = await fetch('https://api.example.com/v1/projects?theme=Star%20Wars&limit=10', {
    headers: {
      'Authorization': `Bearer ${YOUR_API_KEY}`
    }
  });
  const projects = await response.json();
  console.log(projects);
  ```

  ```python
  import requests

  response = requests.get(
      'https://api.example.com/v1/projects',
      params={'theme': 'Star Wars', 'limit': 10},
      headers={'Authorization': f'Bearer {YOUR_API_KEY}'}
  )
  projects = response.json()
  print(projects)
  ```
</CodeGroup>

<Callout kind="tip">
Replace `{YOUR_API_KEY}` with your actual key from the dashboard. Start with the <ParamField path="theme" param-type="string" required="false">query parameter to filter designs.</ParamField>
</Callout>
